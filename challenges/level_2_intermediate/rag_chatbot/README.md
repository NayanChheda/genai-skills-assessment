# RAG Chatbot Challenge

## Objective
Build a Retrieval Augmented Generation (RAG) chatbot that can answer questions based on the provided documents.

## Tasks

### 1. Document Processing
- Implement document loading and chunking
- Create text embedding generation
- Set up vector storage system

### 2. Retrieval System
- Implement similarity search
- Create context retrieval mechanism
- Handle multiple document types

### 3. Generation System
- Integrate with LLM (Large Language Model)
- Implement response generation with context
- Handle conversation history

### 4. Evaluation
- Create evaluation metrics
- Implement quality assessment
- Test with various query types

## Files to Implement
- `document_processor.py` - Document loading and processing
- `retriever.py` - Document retrieval system  
- `generator.py` - Response generation with LLM
- `evaluator.py` - System evaluation metrics

## Starter Code
Basic structure is provided. Implement the missing functionality following the docstrings.

## Assessment
- Retrieval accuracy
- Response quality
- Code organization
- Error handling
- Documentation
