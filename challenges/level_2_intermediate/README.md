# Level 2: Intermediate GenAI Challenges

## Overview
This level focuses on foundational Generative AI techniques including RAG pipelines, prompt engineering, and vector database integration.

## Challenges

### 1. RAG Chatbot
Build a Retrieval Augmented Generation chatbot that can answer questions based on provided documents.

### 2. Prompt Engineering  
Master the art of crafting effective prompts for different AI tasks and scenarios.

### 3. Vector Database Integration
Learn to work with vector databases for efficient similarity search and retrieval.

## Prerequisites
- Python 3.9+
- Basic understanding of NLP concepts
- Familiarity with API interactions

## Assessment Criteria
- Code quality and organization
- Effectiveness of implementations
- Proper error handling
- Documentation and comments
