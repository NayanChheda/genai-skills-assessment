# Level 1 — Git Basics

## Objectives
- Create feature branches, commit with good messages, and open PRs
- Practice fast-forward/merge commits
- Intentionally trigger and resolve a simple merge conflict

## Tasks
1. Create a branch `feature/hello` and add a file `hello.txt` with your name.
2. Open a PR to `main`.
3. On `main`, someone (you) edits the same line to cause a conflict. Resolve it.
4. Merge the PR using the default merge method.

## Acceptance Criteria
- Branch created and PR opened
- Conflict resolved correctly (history clean)
- PR merged and branch deleted
